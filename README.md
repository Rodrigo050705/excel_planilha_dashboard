# 📊💸Dashboard com excel: perda de lucro com "não renovação" 
## Resumo:
Dashboard para visualização e análise de perda no lucro com a não renovação. Aplicando uso de tabelas dinâmicas na base de dados para cálculos (quais renovaram e a soma dos valores) e fórmulas.
### 🛠️Tecnologias Utilizadas:
 - Excel
### 💻Como reproduzir:
- baixar arquivo do excel
- abrir no excel e acessar planilha "Dashboard"
